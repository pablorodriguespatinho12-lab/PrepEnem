## O achado mais importante: o bug das linhas em branco

Desde outubro, comandos de várias linhas perdiam as linhas em branco e as linhas com `#`.
Isso já tinha:

- deixado o `schema.prisma` **inválido** (troca por script que não achava o trecho);
- grudado o corpo de todos os commits no título;
- comido títulos de markdown no logica-app.

A memória dizia "o Bash deste ambiente apaga linhas". **Errado.** A causa é o hook global
`~/.claude/hooks/comment-strip.sh`, que apaga linha em branco e `#` do comando **inteiro**
(inclusive dentro de heredoc e de texto entre aspas). Prova:

```
entrada:  git commit -m a  /  (linha em branco)  /  # b
hook velho devolve: git commit -m a        ← sumiram 2 linhas
hook novo devolve:  (nada muda)
```

Conserto: `scripts/claude-config/comment-strip.sh` só tira comentário do **topo** do comando
(o motivo do hook existir: a lista de permissões ver o comando real).
